# Third-party material

`release/data/v1.0.0/` is a corrected repackaging of a dataset released by
another group. No value in it was altered, rescaled, cleaned, imputed or
augmented; the repackaging changes file layout and headers only, and the
released test suite verifies it cell by cell against the source.
